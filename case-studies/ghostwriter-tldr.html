The Problem

Tailwind users schedule social posts in batches, but writing SEO-friendly captions for each one slowed them down. As AI arrived in SaaS products, Tailwind wanted to add new value for its existing users, speed up scheduling, and make the product stickier. Ghostwriter, an AI tool that generates titles, captions, and more, was the answer, starting inside QuickScheduler, Tailwind's batch scheduler.

My Responsibilities
  • Product designer on Ghostwriter (2022, 3 months), partnering with a Senior Product Designer on its UI and brand
  • Designed the in-line Ghostwriter experience in QuickScheduler's caption field
  • Set guidelines for using Ghostwriter consistently across the app
  • Designed loading-state patterns that work for every generation type
  • Designed the in-app banner that drove adoption of personalized outputs
Key Considerations & Trade-offs
  • Recognizable everywhere. Ghostwriter would show up across the app, so it needed one consistent identity (a ghost icon, button states, labels, and colors) that tells users generation is available.
  • Never block the main task. In QuickScheduler it lives inside the caption field: easy enough to find that it becomes a habit, but out of the way of batch scheduling.
  • Outputs that match intent. Controls for keywords and a call to action, with tooltips explaining why they matter. Users get three options to cycle through and edit in-line, and their outputs are saved if they reopen it.
  • Designing for the wait. Generation takes 5 to 20+ seconds. Engineering explained it's a three-step process, so I went with a simple loading bar and plain-language status labels, the most streamlined option and the easiest to build. I also handed off real-time streaming so users can read the output as it arrives.
Improvements

After launch, the biggest request from users was output that sounded like their business. The team added a personalization profile that only needs the user's website. The next iteration:

  • Designed an in-app banner, placed on the most-used features and written with the marketing team, to get users to set up personalization
  • Trimmed the loading labels as engineering brought generation time down
Outcome
  • Ghostwriter became a recognizable feature across Tailwind, and its shared components save design and dev time as it expands
  • Personalized content generation grew 4x in the first month, and 74% of users make zero edits to personalized output
